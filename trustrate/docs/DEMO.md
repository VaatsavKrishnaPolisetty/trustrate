# TrustRate presentation flow

1. Open the public page and call out the **4.62 Genuine Rating** versus the raw score.
2. Open **Trust & Safety**.
3. Click **Simulate bot-ring**. The alert queue fills with coordinated 5-star reviews.
4. Point to `BURST_POSTING`, `DUPLICATE_TEXT`, and `UNUSUAL_CLIENT` reason codes.
5. Remove an alert and return to the public page; the trusted view updates.
6. Open **Models** and show the `ZZFeatureMap → FidelityQuantumKernel → OneClassSVM` circuit path.
7. Show that the IBM page is hardware-ready, then use `pipeline/hardware_demo.py` once the local token is configured.

If network access or the IBM queue is unavailable, the Aer demo remains fully functional and the UI labels the active backend honestly.
